# Phase 3：功能扩展与差异化（1–3 个月）

> 目标：消灭更新摩擦、提升日常使用深度（多会话、向导、手机）。
> 前置：Phase 2 完成（E2E 与签名是扩展分发的前提）。

## 3.1 引擎自动更新（8 天）

**现状**：desktop 有 update check（仅提示）；引擎更新需整包重装；VSIX 靠市场手动更新。

### Desktop 引擎更新器

1. 复用现有 `updates.ts` 检测逻辑扩展为两级：**客户端自身更新**（electron-updater 或 GitHub Releases 对比）与**引擎更新**（解析上游 stable ref 对比本地 lock）。
2. 更新流程（利用 2.5 的 download 模式基建）：
   ```
   检测新 ref → 后台下载到 ~/.dsh-client/runtime/<new-ref>/ → checksum 校验
   → 托盘提示"引擎更新可用" → 用户确认 → 平滑重启（stop 旧引擎 → 切换目录 → launchHost）
   → 旧版本目录保留一个作为回滚
   ```
3. 失败策略：下载/校验失败保留现版本并提示；连续失败自动降频（每日一次）。
4. 引擎回滚入口：诊断中心加"回滚到上一引擎版本"按钮。

### VSIX

- 接入 Open VSX（Cursor 兼容）+ VS Code 市场双发布，获得自动更新能力；CI 打 tag 时双市场发布（复用 publishing.md 流程，补 GitHub Secrets）。

**验收**：上游发新 release 后 24h 内客户端提示并可一键升级；升级失败可回滚；VSIX 市场自动更新生效。

## 3.2 LAN 手机桥接收尾（10 天）

**现状**：`apps/desktop/src/mobile` 与 `lan-mobile-bridge` 测试已存在，功能"off until Connect Phone"。

**方案**：

1. **配对与安全**（安全红线，不可妥协）：
   - 桌面端展示二维码（已有 qrcode 依赖）：内容为 `https://<LAN-IP>:<port>/connect#<pairing-token>`
   - pairing-token：Crypto 随机 32 字节 base64，5 分钟过期，一次性
   - 手机端打开链接 → 输入/自动携带 token → 服务端校验后发放会话 cookie（HttpOnly + SameSite=Strict）
   - 绑定 **LAN 网卡 IP** 监听（默认仅发现网卡中私网段地址），监听地址在设置中显式可见、可关闭
2. **服务层**：Electron 主进程起 HTTPS（自签证书 + 手机端首次确认指纹）反代到引擎 loopback 端口；注入只读/确认交互降级模式（避免手机端误触破坏性操作——首版可仅"查看 + 批准/拒绝"两类动作）。
3. **UI**：手机端适配页面（`mobile/` 已有雏形，补配对页、会话页、审批卡片）。
4. **测试**：扩展 `lan-mobile-bridge.test.ts`：token 过期、重放、非本网段请求拒绝、TLS 指纹不匹配告警。

**验收**：手机扫码 3 步内连上桌面会话并可通过审批操作；token 重放/过期用例全拒；功能默认可开关。

## 3.3 会话 / 工作区增强（10 天）

| 子项 | 内容 |
|---|---|
| 最近工作区 | desktop 首页与托盘菜单展示最近 10 个 workspace（复用 workspace-choice，持久化到 desktop-settings） |
| 多会话并行 | 多窗口 = 多引擎实例：每实例独立随机端口（`--port 0` 已支持）+ 独立 ready 文件；托盘按工作区名分子菜单；资源上限提醒（并发实例 > 2 时提示内存占用） |
| 崩溃恢复 | 主进程 crash 后重启时检测残留引擎 pid（复用 shutdown 收割逻辑）→ 提示"恢复上次会话 / 直接清理"；VS Code 侧 window restore 同理 |
| 会话命名 | 自动命名（时间 + 工作区名），托盘/窗口标题展示 |

**验收**：同时开 2 个工作区互不干扰；kill 主进程后重启可一键清理/恢复；最近列表可用。

## 3.4 首次启动向导（5 天）

对齐竞品差距分析报告"上手门槛"项：

1. 首启三步向导：选择工作区 → 配置 API Key（复用 api-key 流程）→ 选择引擎模式（下载 / 使用已有）并显示进度。
2. 内置示例工作区模板（1 个最小 demo 项目 + 一段 README），向导最后一步可"打开示例试试"。
3. 中文用户默认展示中文向导（联动 2.6 i18n）。

**验收**：全新用户从安装到第一次对话 ≤ 3 分钟（含引擎下载的口径另行标注）。

- [ ] 手机桥接默认安全策略下可用
