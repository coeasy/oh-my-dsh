# P2：用户体验改进

> 目标：市场加载/安装过程可视化、离线兜底、首次启动引导。
> 优先级：★★★☆☆。

## D1. 插件安装实时进度（client/index.ts）

**现状**：安装仅显示"安装中…"文字，无进度。

**方案**：
1. `install` 路由改为流式/分步返回进度（如 `verify → resolving → installing → reconcile`），前端以事件或轮询更新。
2. 简单起步：前端用阶段文案（`校验中… → 安装中… → 写入配置…`）替代单一"安装中…"。
3. 安装完成后明确"成功，需重启生效"提示；失败时展开 `output` 面板。

**验收**：安装过程有阶段反馈；失败可查看命令输出。

## D2. 离线兜底与提示

**现状**：所有在线源超时后，列表只剩 builtin 快照，但用户无感知。

**方案**：
1. 前端聚合 `sources` 的 `ok` 状态：在线源全部失败时显示"当前为离线内置快照"提示条。
2. 提供"重试加载在线源"按钮（触发 refresh）。
3. 离线时禁用来源切换中对在线源的依赖逻辑，避免误导。

**验收**：断网场景有明确提示；重试按钮可用。

## D3. 骨架屏替代纯 spinner

**现状**：已实现"正在加载数据源 X/Y"文本 + spinner。

**方案**：在数据到达前渲染 3–5 张骨架卡片（灰色占位块），数据逐源到达后替换为真实卡片，视觉更顺滑。

**验收**：首屏无空白跳动，骨架→内容过渡平滑。

## D4. 首次启动引导

**现状**：无 API Key 引导。

**方案**：检测无 API Key 时，弹首次引导卡片：说明用途、引导配置 Key 的入口，可关闭。

**验收**：新用户首启有引导，老用户不被打扰。

## D5. VS Code 端市场入口（可选）

**现状**：市场仅桌面端有入口。

**方案**：VS Code Webview 面板增加"插件市场"标签页，复用同一 dsh web 市场插件（一次覆盖两端）。

**验收**：VS Code 内可浏览/安装插件。

## 落地状态（2026-08-19）

- ✅ **D1**：`client/index.ts` 的 `act()` 阶段化反馈：`正在执行安装前安全校验… → 正在通过官方 CLI 安装… → 正在刷新安装状态…`，安装等待不再是黑盒；失败时输出面板保留官方 CLI 完整输出。
- ✅ **D2**：在线源全部失败时显示离线提示条（内置快照兜底）+ **重试按钮**（一键 `refresh=1` 重载在线源）。
- ✅ **D3**：首屏骨架屏（3 张占位卡片 + spinner + 进度文本"正在加载数据源 X/Y"），数据到达后平滑替换。
- ✅ **D4**：首次启动 `setup.html` 引导卡片（工作区选择 + API Key 输入 + 跳过选项，中英双语）；已提示过但未配置 Key 时自动跳过引擎端全屏 onboarding（preload `autoSkipOnboarding`）。
- ⏸ **D5**：暂缓（VS Code 端市场入口），后续按需排期。

另：B6 启动阶段进度已落地 —— `launchHost` 上报 `resolving → downloading → spawning → waiting-ready → ready`，桌面端 splash 实时更新阶段文案（中英双语）。
