# 国际化（i18n）指南

> 更新：2026-08-18

## 目标

让客户端**壳层**（托盘、设置、启动、手机桥接）与**文档**支持中英文，并按用户系统语言自动切换。引擎 Web SPA 的界面由上游 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 负责，本仓库不维护 SPA 文案。

## 语言选择

| 场景 | 语言判定 | 说明 |
|---|---|---|
| 托盘 / 主进程 | `app.getLocale()` 前缀为 `zh` → 中文，否则英文 | `status-tray.ts` / `app-tray.ts` |
| setup.html / splash.html | `navigator.language` 前缀为 `zh` → 中文 | 静态 HTML 内嵌 JSON 切换 |
| 手机桥接页 | `navigator.language` 前缀为 `zh` → 中文 | `mobile/lan-mobile-pages.ts` |
| 文档 README | 中英双语文件并存 | `README.md`（英文）+ `README.zh-CN.md`（中文） |

## 代码层覆盖

### 主进程 / 托盘（Electron）

- `apps/desktop/src/status-tray.ts` —— 托盘提示文案与菜单标签，导出 `trayTooltip()` 与 `trayMenuLabels(locale)`，内置 `en` / `zh` 资源。
- `apps/desktop/src/app-tray.ts` —— `createStatusTray()` 接收 `locale: 'en' | 'zh'`，据此生成托盘菜单与 tooltip。

### 静态页面（HTML）

- `apps/desktop/setup.html` —— 首启设置页，`zh` 分支切换全部字段标签与按钮。
- `apps/desktop/splash.html` —— 启动画面，品牌字标 + 状态文案。
- `apps/desktop/src/mobile/lan-mobile-pages.ts` —— LAN 手机桥接配对 / 会话页，返回双语 HTML。

## 新增一种语言

当前采用**轻量字典**而非重依赖 i18n 框架，新增语言只需两步：

1. **TS 层**：在 `status-tray.ts` 的 `PHASE_LABEL` 与 `trayMenuLabels()` 中新增一个 locale 键（如 `'ja'`），并补充对应文案。
2. **HTML 层**：在 `setup.html` / `splash.html` 的语言分支中追加 `if (isJa) { ... }` 文本替换，或抽出为独立的 `<script type="application/json">` 字典并按 `navigator.language` 选取。

> 建议后续将 `setup.html` / `splash.html` 的文案抽为同一份 JSON 资源，与 TS 层共享，避免重复维护。

## 回退策略

- 未知 locale 一律回退英文。
- 缺失 key 时回退英文并在控制台 `console.warn`。

## 验收

- 系统语言为中文时：托盘提示为 `my-dsh · 运行中`，设置页为中文，手机桥接页为中文。
- 系统语言为英文时：以上均为英文。
- `pnpm test` 覆盖 `status-tray`（中英两种）与手机桥接页。
